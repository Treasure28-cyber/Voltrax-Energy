# Voltrax Energy Website Documentation

This folder is the source of truth for the design and development of the Voltrax Energy Nigeria Limited website.

## Project summary

Build a clean, professional, responsive two-page product-catalogue website for a Nigerian solar and electrical-products company. Visitors should be able to understand the company, browse and filter products, and send a product-specific enquiry through WhatsApp.

## Technology baseline

- React 19 with Vite
- React Router
- Tailwind CSS
- Lucide React icons
- Local JSON product data
- Static deployment to Netlify
- Custom `.com` domain purchased separately

Use current stable package versions available when implementation begins. Do not add a backend, database, CMS, authentication, cart, checkout, or payment system.

## Instructions for the developer or coding agent

- Read every document before changing code.
- Treat explicit requirements as authoritative.
- If a real asset or company detail is unavailable, use a clearly marked placeholder and centralize it for easy replacement.
- Do not invent certifications, partnerships, years of experience, customer statistics, addresses, prices, warranties, or testimonials.
- Build the approved two-page scope before suggesting enhancements.
- Record material assumptions in the project README produced with the code.
